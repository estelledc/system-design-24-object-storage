## Required integration matrix

- bucket and object mutation exact replay versus changed-intent conflict;
- three published/readback copies, two-copy visibility threshold, and no visibility after first-copy crash;
- PUT metadata commit before response loss creates exactly one version and one current pointer;
- overwrite precondition, explicit old-version read, tombstone current read, and delete response loss;
- preferred-replica corruption, full-digest fallback, one repair task, stale-generation rejection, verified repair;
- single-range boundary and full-object verification before slicing;
- immutable multipart part replay/conflict, missing/reordered part rejection, abort/expiry, completion response loss;
- materialized list pages unchanged after later PUT/DELETE;
- orphan detection after pre-metadata crash, recent-retention abstention, stale GC fence, fresh reachability recheck, deletion receipt;
- invariant/state output and privacy-bounded logs.

## True-process crash points

| Hook | Expected recovery |
|---|---|
| `OBJECT_CRASH_AFTER_FIRST_REPLICA` | process exits after one sync/rename/readback; no visible version; exact retry adopts/fills |
| `OBJECT_CRASH_AFTER_PUT_COMMIT` | one committed version; exact retry replays original result |
| `OBJECT_CRASH_AFTER_PART_COMMIT` | one immutable part receipt; exact retry replays, changed part conflicts |
| `OBJECT_CRASH_AFTER_COMPLETE_COMMIT` | one completed upload/version; exact retry replays |
| `OBJECT_CRASH_AFTER_DELETE_COMMIT` | one current tombstone; exact retry replays |

Each kill is a separate OS process observed by an external test driver. Throwing an exception in the same process is not equivalent.

## Benchmark contract

The fixed benchmark will report exact observations for:

- 64 objects of 16 KiB generated content, three attempted same-host copies and a two-copy visibility threshold;
- 64 verified full reads plus bounded range reads;
- one four-part 64 KiB completion;
- 16 list snapshots/pages;
- one corrupt-copy fallback and repair;
- one orphan scan and retention-aware GC;
- Node/PostgreSQL/platform versions, elapsed milliseconds, logical bytes, attempted physical bytes, file counts, and operation counts.

The output must also state `sameHostOnly`, `s3CompatibilityProved: false`, `durabilityPercentageProved: false`,
`backupRestoreProved: false`, and `externalAcceptanceProved: false`. It is not a throughput, latency, SLA, capacity, or cloud-cost
claim.
