# Security policy

This repository accepts synthetic `.invalid` identities, lab bucket/key identifiers, and generated bounded bytes only. Do not file
issues with credentials, signed URLs, access keys, real object contents, customer bucket/key names, cloud endpoints, account IDs,
internal topology, malware samples, or production logs.

Report a suspected vulnerability privately through the repository security advisory flow. v0.1 is a loopback/local-filesystem
learning lab, not a public object store, S3-compatible service, backup product, or production security boundary.
